# ThirdReality Smart Scale

Home Assistant custom integration for ThirdReality Smart Scale (3RKS030Z).

**Features:**
- Cocktail Mixing Assistant — step-by-step guided mixing with voice
- Calorie Tracker — real-time calorie counting with smart warnings
- Voice guidance works best with ThirdReality smart speakers
- Auto-creates all helper entities — zero manual setup!

**Supported platforms:** Zigbee2MQTT, ZHA

**Setup:** Settings → Add Integration → ThirdReality Scale → Follow wizard

# ThirdReality Smart Scale

Home Assistant custom integration for ThirdReality Smart Scale (3RKS030Z).

**Features:**
- Cocktail Mixing Assistant — step-by-step guided mixing with auto-advance
- Calorie Tracker — 160+ food presets, 7-day history, streak tracking
- Built-in sidebar panel 
- Voice guidance works with ThirdReality smart speakers or any media_player
- g / oz unit toggle

**Supported platforms:** Zigbee2MQTT, ZHA

**Setup:**
1. Settings → Add Integration → ThirdReality Smart Scale → Follow wizard
2. "Smart Scale" appears in the sidebar automatically
3. Done — no blueprints or dashboard YAML needed

See [README](https://github.com/thirdreality/ha-thirdreality-scale) for detailed instructions.

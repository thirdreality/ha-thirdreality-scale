# ThirdReality Smart Scale

Home Assistant custom integration for ThirdReality Smart Scale (3RKS030Z).

**Features:**
- 🍸 Cocktail Mixing Assistant — step-by-step guided mixing with voice
- 🔥 Calorie Tracker — real-time calorie counting with smart warnings
- 🔊 Voice guidance works best with ThirdReality smart speakers
- Auto-creates all helper entities (buttons, sensors, selects, etc.)

**Supported platforms:** Zigbee2MQTT, ZHA

**Setup:**
1. Settings → Add Integration → ThirdReality Scale → Follow wizard
2. Import Blueprints (one-click buttons in README)
3. Create automations from the imported blueprints
4. Import dashboard YAML (instructions in README)

See [README](https://github.com/thirdreality/ha-thirdreality-scale) for detailed setup instructions.
